Do I need to create a Project?

No.

Claude Code on the web needs a GitHub repo and an environment. That’s it. “Projects” in regular claude.ai chat are a separate feature.

Level 1 · the flowchart →

Where are my knowledge files stored?

In your GitHub repo.

Put a CLAUDE.md and a docs/ folder there. Every session starts from a fresh copy of the repo.

Level 2 · the storage map →

Are they persistent?

The repo is. The cloud computer isn’t.

Each session runs on a temporary computer that gets reclaimed when it sits idle. Commit and push, or lose it.

Level 3 · the self-destruct game →

Can I add logins and a database?

Yes. Supabase, Pinecone, and more.

Use a connector, or store the key in environment settings and allow the domain. Your data lives in the database, so it survives.

Level 4 · the wiring puzzle →

How do I set it up?

Ten plain steps.

Sign in, connect GitHub, pick a repo, pick an environment, add secrets the safe way, then type what you want.

Level 5 · the speedrun →

How is it different from Desktop?

Their computers vs. yours.

The web version runs on Anthropic’s computers and keeps going when your laptop is closed. Desktop runs on your computer and sees your local files.

      Plug in a real database.

      Yes, you can use Supabase, Pinecone, and real logins from the cloud. The cloud computer forgets, but the database remembers. Your data lives in the database, so it survives every session.

        Supabase

        A Postgres database with logins, file storage, and APIs built in. A good home for users, orders, and app data.

        Pinecone

        A vector database. It stores meaning, so AI apps can search notes and documents by idea instead of exact words.

        Auth (logins)

        Your app’s sign-in system. Supabase Auth handles passwords, magic links, and Google sign-in. Claude writes the code. The keys stay in environment settings.

          How to work with it, daily.

          • One task per session. Small, clear jobs finish faster and are easier to review.
          • Ask for a plan first on big changes: “Show me your plan before you write code.”
          • Changed settings or connectors? Start a new session. Sessions read them when they start.
          • Run several at once. Each session gets its own cloud computer.
          • Check in from your phone. Sessions keep running when your laptop is closed.
          • Secrets stay out of chat and out of the repo. Environment settings only.
