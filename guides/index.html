One prompt · two builds · same six questions

Pick your guide.

Both guides answer the same questions about Claude Code on the web: do you need a Project, where your files live and whether they last, how to add logins and a database, how to set it up, and how it differs from Desktop. They play very differently.

Version 1 · Oct 2, 2026 +20 XP

Claude Code Web Quest

A friendly, Duolingo-style quest. Nine levels with XP, badges, and a cheerful cloud named Nimbus who walks you from first login to first merge.

Design
Refero reference: Duolingo. Mint canvas, candy greens and blues, rounded type, pressable 3D buttons.
Shape
9 levels, 10 badges, a boss quiz with three hearts and a certificate.
Theme
Light and dark, with a toggle.
  • Flip cards with the short answer on the front and the full story on the back
  • Animated setup flowchart with a “pretend my repo is missing” detour
  • Vault or sandcastle sorting game, then a wave washes the sandcastle away
  • Trap room pre-mortem: ten ways it fails, each with a Disarm button
Open Web Quest
Version 2 · Oct 3, 2026

Claude Code Cloud Cartridge

A sarcastic handheld-console game. Crank the screen, beat the self-destruct timer, and get roasted by Cranky, a cloud with opinions.

Design
Refero references: Playdate for the lemon, charcoal, and violet handheld with a crank. Obscura for pixel headlines and pixel clouds.
Shape
6 levels plus a boss quiz, 16 achievements with XP.
Theme
One fixed arcade look on any screen.
  • A console you drive by dragging its crank, with a 1-bit animated screen
  • Commit-and-push mini-game where unpushed files explode
  • Leak Detector 3000: paste something that looks like a key and the sirens go off
  • Web vs Desktop fight that ends in a double K.O.

Which one should I open?

Sharing with someone new to this?

Open Web Quest. It is calm, step by step, and has a light and a dark mode.

Want it to stick through jokes and games?

Open Cloud Cartridge. The mini-games make the save-your-work lesson hard to forget.
